## TOY ML PROJECT

This toy-project is made by me to have a bird's view over the MLDLC: Machine Learning Development Pipeline. Dtaset used here is a synthetic dataset which has IQ, CGPA, Placements as columns/features.

IQ and CGPA are input features and Placement as target feature.

Followed a specific ML template where we first import csv dataset file, perform EDA, scale the features, as IQ and CGPA are in different scales. Decided to chose Logistic Regression as we have to find placement as yes/No based on the IQ and CGPA inputs. After scaling we performed a train test split, where 80% Training data and 20% Tesing data was taken from dataset./ The model accuracy came out to be 80%, which is good for toy-model and synthetic dataset.

This toy-project was enough to give me a glimpse of how ML models given data, trained and then tested and at last selected for further evaluation.
